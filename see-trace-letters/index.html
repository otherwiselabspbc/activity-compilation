About this activity

Corpus entry. ORT-04 · Orthographic Knowledge › Tactile Only › See, Trace › See Letter, Trace Letter.

Units. Letter Units: Group 1 (lower-case a–z) or Group 2 (upper-case A–Z). Each run uses 3–7 letters of one group. The default set is the circle-first family (c, o, a, d, g), which share one movement.

The exercise. The child sees one letter with numbered start dots and direction arrows and traces it with a finger or stylus. Tracing is scored on stroke count, order, start point, direction, and staying on the path, not on neatness. A first mistake gets a short line that names it and a demonstration, then another try; a second mistake moves on, and the letter comes back later. No letter name or sound is ever spoken.

Letterforms. Strokes follow the repository's ball-and-stick convention (v1): b, h, m, n, p, r, u are one stroke that runs back up the stick; a, d, g, q start with the circle. Accepted variants (a lift where the line doubles back, a, d, g, q in one continuous stroke, and a right-to-left crossbar for left-handers) are scored correct and logged.

What it reports. Per item: unit, outcome and formation sub-state, every stroke's metrics, accepted variants, latency, attempts, hints, and scaffold state. It never decides mastery or what comes next.

Open decisions carried in this build

Narration voiceUntil recorded narration exists, instructions use the device's built-in speech. Every line is keyed in the narration manifest for recording. Recordings are needed before use with children.
Trace tolerancesFinger input uses a slightly looser band than stylus input. Both are starting values to tune on real traces.
Typeface checkG, J, M, Q and t are to be compared with the displayed typeface before release (convention HW-10).
