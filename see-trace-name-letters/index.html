About this activity

Corpus entry. Orthographic Knowledge › Tactile, Speech › See, Trace, Name › See Letter, Trace Letter, Say Letter Name.

Units. Letter Unit: Group 1 (lower-case a–z) or Group 2 (upper-case A–Z). Each run uses 3–7 letters of one group.

The exercise. The child sees one letter with formation cues, traces it with a finger or stylus, and then says its name. Tracing is scored on stroke order, direction, start point, and staying on the path. The name is heard through the browser's speech recognizer; when listening is not possible, or a name cannot be heard clearly, the child taps the name among three spoken choices instead, and that is recorded as a different measure.

What it reports. Per item: unit, tracing outcome and formation sub-state, naming outcome with what was heard and how sure the recognizer was, latencies, attempts, hints, scaffold state, and which response mode decided the item. It never decides mastery or what comes next.

Open decisions carried in this build

Narration voiceUntil pre-generated voice assets exist, narration uses the device's built-in speech. Every line is already keyed in the narration manifest for recording. Delivery mode is stamped on every result.
Speech recognitionLetter names are heard through the browser's Web Speech API as an interim recognizer. Audio goes to the browser vendor's service and the network is required. Names that sound alike (b/d/p/e/t/v/g/c/z, a/j/k/h, f/l/m/n/s/x, i/y, u/q/w) cannot be told apart reliably, so those are scored as uncertain and settled by tapping, never marked wrong on speech alone.
Handwriting conventionThe corpus does not name a handwriting program. Stroke order here is a provisional ball-and-stick print manuscript (single-story a and g; barred capital I). Swap the stroke files once a program is chosen.
Trace tolerancesFinger input uses a slightly looser band than stylus input. Both are starting values to tune on real traces.
