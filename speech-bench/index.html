Speech test bench

For testing the shared speech module with a grown-up's own voice. Not an activity for children.

How it works. A letter appears and the page says "Say this letter." Say the letter's name at a normal pace. If the page says "Say it again?", say it again. Say every letter correctly: the bench measures how often the recognizer hears a correct answer.

Use Chrome in a quiet room. Speak from where a child would sit. Each setup takes about 2 minutes for a–z.

The page records nothing. What the browser's speech service returns (text only) is shown on screen and kept in the results you copy. In Chrome, audio goes to Google's speech service.
